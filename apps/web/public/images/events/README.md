# Event artwork

Original environment PNG banners downloaded on 2026-10-22 from the Statscell Brawl Stars asset archive:

https://github.com/Statscell/brawl-assets/tree/d3f88993093046d8cafb511e441b0358d30ac061/environments

These PNG originals are preserved without resizing or recompression.

The hockey, basketball, Windstock, hub, and ghost train banners come from the game's version 69.230 `sc/events.sc` assets:

https://github.com/tailsjs/brawl-stars-assets/blob/cc307ffd36678ac463cc2ca9373a08b0a2d2b0b7/69.230/sc/events.sc

They are 1600 × 512 lossless PNG renders generated by the Rust program in `apps/event-artwork`. It uses the first animation frame, embedded high-resolution ASTC textures, Catmull-Rom bicubic sampling with premultiplied alpha, and antialiased polygon coverage. Rendering happens directly at output resolution in a centered 200 × 64 game-unit viewport. Source texture resolution and compression still limit the detail available; larger PNG dimensions do not create new source detail.

See `apps/event-artwork/README.md` for generation commands and supported formats. Named exports, dimensions, and source URLs are recorded in `apps/web/shared/data/event-artwork.json`. Brawl Arena and Knockout 5v5 currently share the Windstock environment; Hot Zone uses the hub environment. Mode fallbacks also cover hockey, basketball, and Hot Zone variants when environment metadata is unavailable.

Mode icons are from Brawlify. Exact source URLs and the environment-to-banner mapping are recorded in `apps/web/shared/data/event-artwork.json`. All game artwork belongs to Supercell.
